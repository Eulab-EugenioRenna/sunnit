# DevSecOps Engineer

## About the position
We are looking for a **DevSecOps Engineer** to integrate security throughout the entire software development lifecycle, automating controls and strengthening the company's infrastructure.

## Responsibilities
*   Integrate security practices into CI/CD pipelines (**shift-left security**).
*   Automate vulnerability analysis (**SAST, DAST, SCA**).
*   Manage the security of containers and orchestrators (**Docker, Kubernetes**).
*   Define secret management and access control policies.
*   Collaborate with development, cloud, and security teams to reduce risks.

## Requirements
*   **Experience:** Minimum of 3 years in DevOps or Security roles.
*   **CI/CD:** Experience with tools such as GitLab CI, Jenkins, or GitHub Actions.
*   **Cloud:** Knowledge of cloud security (AWS, Azure, or GCP).
*   **Security:** Experience with scanning tools such as Snyk, Trivy, or SonarQube.
*   **Infrastructure:** Knowledge of IaC (Terraform, Ansible) and containers.

## Desirable/Plus
*   **Certifications:** CKS, CompTIA Security+, or OSCP.
*   **Secrets Management:** Experience with Vault or AWS Secrets Manager.
*   **Compliance:** Knowledge of ISO 27001 or SOC 2 standards.
