# DevSecOps Engineer

## Informazioni sulla posizione
Cerchiamo un/a **DevSecOps Engineer** per integrare la sicurezza in tutto il ciclo di vita dello sviluppo del software, automatizzando i controlli e rafforzando l'infrastruttura dell'azienda.

## Responsabilità
*   Integrare pratiche di sicurezza nelle pipeline CI/CD (**shift-left security**).
*   Automatizzare l'analisi delle vulnerabilità (**SAST, DAST, SCA**).
*   Gestire la sicurezza di container e orchestratori (**Docker, Kubernetes**).
*   Definire politiche di gestione dei segreti e controllo degli accessi.
*   Collaborare con i team di sviluppo, cloud e sicurezza per ridurre i rischi.

## Requisiti
*   **Esperienza:** Minimo 3 anni in ruoli DevOps o Sicurezza.
*   **CI/CD:** Esperienza con strumenti come GitLab CI, Jenkins o GitHub Actions.
*   **Cloud:** Conoscenze di sicurezza nel cloud (AWS, Azure o GCP).
*   **Sicurezza:** Esperienza con strumenti di scansione come Snyk, Trivy o SonarQube.
*   **Infrastruttura:** Conoscenze di IaC (Terraform, Ansible) e container.

## Saranno valutati
*   **Certificazioni:** CKS, CompTIA Security+ o OSCP.
*   **Gestione dei Segreti:** Esperienza con Vault o AWS Secrets Manager.
*   **Compliance:** Conoscenze delle normative ISO 27001 o SOC 2.
