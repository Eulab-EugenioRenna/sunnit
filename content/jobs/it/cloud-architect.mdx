# Cloud Architect

## Informazioni sulla posizione
Cerchiamo un/una **Cloud Architect** per guidare la progettazione di architetture cloud scalabili, sicure ed efficienti in termini di costi, orientando i team tecnici verso le migliori pratiche di infrastruttura.

## Responsabilità
* **Progettazione di Architetture:** Creare architetture cloud (multi-cloud o ibride) allineate con le esigenze di business.
* **Standard Tecnici:** Definire standard di sicurezza, scalabilità e resilienza.
* **Automazione:** Guidare l'adozione dell'Infrastruttura come Codice (IaC).
* **Ottimizzazione:** Gestire e ottimizzare i costi cloud (FinOps).
* **Mentoring:** Consulenza ai team di sviluppo e DevOps sulle decisioni di architettura.

## Requisiti
* **Esperienza:** Minimo 5 anni in architettura cloud.
* **Piattaforme:** Padronanza di almeno una piattaforma cloud (AWS, Azure o GCP); è valutata positivamente la conoscenza di più piattaforme.
* **Strumenti IaC:** Esperienza con Terraform, CloudFormation o strumenti simili.
* **Competenze Tecniche:** Solide conoscenze di networking, sicurezza e container (Kubernetes, Docker).
* **Certificazioni:** Certificazioni cloud di livello architect (es. AWS Solutions Architect Professional).

## Saranno valutati
* Esperienza in migrazioni cloud su larga scala.
* Conoscenze di architetture serverless ed event-driven.
* Esperienza nella guida di team tecnici.
