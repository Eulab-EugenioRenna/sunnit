# DevSecOps Engineer

## Sobre el puesto
Buscamos un/a **DevSecOps Engineer** para integrar la seguridad en todo el ciclo de vida del desarrollo de software, automatizando controles y fortaleciendo la infraestructura de la compañía.

## Responsabilidades
*   Integrar prácticas de seguridad en pipelines CI/CD (**shift-left security**).
*   Automatizar análisis de vulnerabilidades (**SAST, DAST, SCA**).
*   Gestionar la seguridad de contenedores y orquestadores (**Docker, Kubernetes**).
*   Definir políticas de gestión de secretos y control de accesos.
*   Colaborar con equipos de desarrollo, cloud y seguridad para reducir riesgos.

## Requisitos
*   **Experiencia:** Mínima de 3 años en roles de DevOps o Seguridad.
*   **CI/CD:** Experiencia con herramientas como GitLab CI, Jenkins o GitHub Actions.
*   **Cloud:** Conocimientos de seguridad en la nube (AWS, Azure o GCP).
*   **Seguridad:** Experiencia con herramientas de escaneo como Snyk, Trivy o SonarQube.
*   **Infraestructura:** Conocimientos de IaC (Terraform, Ansible) y contenedores.

## Se valorará
*   **Certificaciones:** CKS, CompTIA Security+ u OSCP.
*   **Gestión de Secretos:** Experiencia con Vault o AWS Secrets Manager.
*   **Compliance:** Conocimientos de normativas ISO 27001 o SOC 2.
