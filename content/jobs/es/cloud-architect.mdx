# Cloud Architect

## Sobre el puesto
Buscamos un/a **Cloud Architect** para liderar el diseño de arquitecturas cloud escalables, seguras y eficientes en costes, guiando a los equipos técnicos en las mejores prácticas de infraestructura.

## Responsabilidades
* **Diseño de Arquitecturas:** Crear arquitecturas cloud (multi-cloud o híbridas) alineadas con las necesidades del negocio.
* **Estándares Técnicos:** Definir estándares de seguridad, escalabilidad y resiliencia.
* **Automatización:** Liderar la adopción de Infraestructura como Código (IaC).
* **Optimización:** Gestionar y optimizar costes cloud (FinOps).
* **Mentoría:** Asesorar a equipos de desarrollo y DevOps en decisiones de arquitectura.

## Requisitos
* **Experiencia:** Mínima de 5 años en arquitectura cloud.
* **Plataformas:** Dominio de al menos una plataforma cloud (AWS, Azure o GCP); se valoran varias.
* **Herramientas IaC:** Experiencia con Terraform, CloudFormation o herramientas similares.
* **Conocimientos Técnicos:** Sólidos conocimientos de redes, seguridad y contenedores (Kubernetes, Docker).
* **Certificaciones:** Certificaciones cloud de nivel arquitecto (ej. AWS Solutions Architect Professional).

## Se valorará
* Experiencia en migraciones cloud a gran escala.
* Conocimientos de arquitecturas serverless y event-driven.
* Experiencia liderando equipos técnicos.
