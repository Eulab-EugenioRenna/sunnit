# Data Engineer

## Sobre el puesto
Buscamos un/a **Data Engineer** para diseñar y mantener pipelines de datos robustos y escalables que alimenten los productos analíticos y de IA de la compañía.

## Responsabilidades
* Diseñar, construir y mantener pipelines ETL/ELT.
* Modelar y optimizar almacenes de datos (Data Warehouse / Data Lake).
* Garantizar la calidad, gobernanza y trazabilidad de los datos.
* Colaborar con equipos de analítica, producto y GenAI para exponer datos de forma eficiente.
* Automatizar procesos de ingesta y orquestación de datos.

## Requisitos
* Experiencia mínima de 3 años en ingeniería de datos.
* Dominio de **SQL** y **Python** (o Scala).
* Experiencia con herramientas de orquestación (**Airflow, Dagster, Prefect**).
* Conocimientos de plataformas cloud (**AWS, Azure o GCP**).
* Experiencia con tecnologías Big Data (**Spark, Kafka, Databricks**).

## Se valorará
* Experiencia con **dbt** (data build tool).
* Conocimientos de arquitecturas **Data Mesh** o **Lakehouse**.
* Certificaciones cloud (AWS/Azure/GCP Data Engineer).
